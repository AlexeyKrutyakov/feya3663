# 12. Главная страница — 3D-сцена (эмблема-фея)

> Спецификация визуальной фичи главной страницы. Решения D28–D31 — в `01-open-questions.md`.
> Исходники эмблемы: `tmp/fairy/` (gitignored, вне git — см. «Исходники»).

## Суть

Главная страница — интерактивная 3D-сцена на весь вьюпорт (без текста и других
элементов): эмблема клиники (фея со звёздами), объёмная «как монета», со
звёздами-кнопками навигации. По мнению заказчика — главная визуальная фича
приложения; основной функционал (расписание/запись) — за ней.

## Технологии (D28)

- **React Three Fiber + drei** (R3F), поверх three.js. Обоснование: R3F —
  консенсус для React-сцен (декларативность, raycasting-события из коробки);
  чистый three.js в React создаёт «два мира» (форум three.js, офиц. док-ция R3F).
  R3F уже заложен в стек (D17).
- Next.js App Router: `<Canvas>` в `'use client'`-компоненте, загрузка через
  `next/dynamic` c `ssr: false` — three.js (~600 КБ) не блокирует LCP.
- Ориентир-стартер: `pmndrs/react-three-next`.

## Геометрия (D29)

- Источник — векторная эмблема (SVG-path'ы). Объём — **экструзия в рантайме**:
  SVGLoader → `THREE.Shape` → `ExtrudeGeometry` с фаской (bevel).
- Иерархия толщин: фея — толще всех; зуб и кликабельные звёзды — тоньше;
  декоративные звёзды 05/06 — тонкие плашки. Настраивается, подбирается на
  прототипе.
- План Б — запекание в glTF (Blender/конвертер), если рантайм-экструзия даст
  плохие фаски или долгую генерацию (~15 path'ов — ожидаемо быстро).
- Гочака SVGLoader: Y-координаты SVG инвертированы относительно 3D.

## Навигация (D30)

| Элемент | MVP | Назначение |
|---------|-----|------------|
| Зуб | ✅ кликабелен | `/schedule` (Расписание) — приоритетная страница |
| Звезда 01 (слева, крупная) | ✅ кликабельна | `/about` («Обо мне» — о главном враче/ИП) |
| Звёзды 02–04, 07 | 🟨 резерв | назначаются будущим фичам |
| Звёзды 05, 06 | ❌ декор | часть логотипа |

«Регистрация/Вход» — **не кнопка на сцене**: неаутентифицированных
редиректим на вход с защищённых страниц (middleware).

Клик по мешу = `router.push` тем же маршрутом, что и у фолбэк-ссылок (см.
«Доступность»).

## Взаимодействие (D31)

- **Десктоп:** OrbitControls с жёсткими ограничениями — зум ±~15% (колёсико),
  облёт ±~10° по орбите/высоте, без панорамирования. Декоративная
  «играемость» — цель, не навигация.
- **Мобильные:** управление, перехватывающее скролл (пальцевый облёт,
  pinch-зум), по умолчанию выключено; камера — лёгкий авто-дрейф/параллакс.
  Точный режим (кнопки «+/−», «активация по тапу») — на усмотрение
  реализации, уточним на прототипе.
- **Idle-анимации:** мерцание звёзд (наследие SVG-черновика), медленное
  покачивание звёзд по Z.

## Подписи и стиль

- Подписи кнопок видимы **постоянно на десктопе** (иначе кликабельность не
  очевидна за «игрой» с камерой); на мобильных — подпись по касанию/подсказка.
  Рендер — `drei/Html` (DOM поверх меша).
- Материалы: matte («матовый пластик»), мягкий студийный свет, лёгкая фаска.
  Цвета — из дизайн-системы (`08-design-system.md`), не хардкодом; текущая
  палитра-референс: бежевые звёзды/зуб, тёмно-зелёный текст.
- Стиль намеренно простой — правится заменой материала/света, без переделки
  геометрии.

## Доступность и фолбэк (D28)

- WebGL недоступен / ошибка инициализации → рендерим плоский SVG-вариант
  сцены (портируем черновик из `tmp/fairy/` в `apps/web` как фолбэк-компонент).
- Клавиатура/скринридер: скрытый `<nav>` с обычными `<a>`-ссылками на те же
  маршруты.
- Анимации уважают `prefers-reduced-motion`.

## Исходники эмблемы (в `tmp/`, gitignored)
